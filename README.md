📊 Presentación Personal – Portafolio de Excel
Soy un profesional con sólidos conocimientos en Microsoft Excel, enfocado en el análisis de datos, automatización de tareas y generación de reportes eficientes. Manejo funciones avanzadas, tablas dinámicas, segmentación de datos, validación de información, gráficos personalizados, dashboards interactivos y herramientas de análisis como Solver y Buscar Objetivo.
Además, tengo experiencia en el uso de macros con VBA para automatizar procesos repetitivos y mejorar la productividad.

Mi objetivo con este portafolio es mostrar de manera clara y práctica cómo aplico Excel para resolver problemas reales en áreas como control de inventarios, seguimiento de indicadores, gestión financiera, planificación y análisis de datos empresariales.
